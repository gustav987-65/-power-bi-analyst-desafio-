# Power BI Analyst — Desafio de Projeto

Projeto prático do curso de Power BI Analyst da DIO — replicando e evoluindo o dashboard de vendas com uma nova página de análise por país e segmento.

## 📊 Sobre o desafio

O desafio consistiu em criar uma terceira página de relatório no Power BI, complementando as duas páginas já desenvolvidas durante o curso, com foco em visualizações geográficas e de segmento.

## 🗺️ Visuais criados

**Página 3 — Visão por País e Segmento**

- **Mapa 1:** Soma de Sales (Vendas) e Units Sold (Unidades Vendidas) por País
- **Mapa 2:** Soma de Profit (Lucro) por País
- **Gráfico de Pizza:** Soma de Profit por Segment (Segmento)

## 🎨 Design

- Paleta de cores personalizada para diferenciar claramente os segmentos no gráfico de pizza
- Cabeçalho com título destacado no topo da página
- Layout organizado: mapas lado a lado na parte superior, gráfico de pizza ocupando a largura total na parte inferior
- Nomes de visuais renomeados para maior clareza
- Dicas de ferramenta (tooltips) revisadas em cada visual

## 📁 Dados utilizados

Base de dados **Financial Sample**, contendo informações de vendas, lucro, unidades vendidas, país e segmento de mercado.

## 🛠️ Ferramentas

- Power BI Desktop
- Base de dados: Financial Sample.xlsx
